pi-graph pi agent · orchestration chart room

夜间勘测图纸 · Night Chart Room

把 pi agent 的每一次会话，
画成一张可勘测的图

pi-graph-ui 是 pi agent 的可视化驾驶舱：实时事件图把会话流画成节点， ⚡ 自动编排把一个目标拆成任务 DAG 并立即执行， 编辑器与历史回放收进同一张暗色图纸—— 蓝墨是行进中的航线，洋红是测绘员的手，虚线是尚未勘测的地面。

node scripts/dev.mjs → 打开 :5173 看能力清单

能力

六个站牌，各司其职——图是主线，其余都为读图服务。

LIVE

实时事件图

会话事件流即刻成图：工具调用、子代理扇出、流式回复都是节点。状态用四色 + 方点/✗ 字形双通道表达，色弱也能读。

PLAN

⚡ 目标自动编排

输入一个目标，规划器拆成任务 DAG 并立即执行：规划草稿流式预览、并行上限 4、上游失败自动跳过下游；完成后结果注入会话并整合为一段回答。

EDIT

DAG 编辑器

模板起步，拖拽建节点、连线定依赖；边带类型（输入/参考/审校）与备注，校验问题即点即见，坏图跑不起来。

HIST

历史回放

会话自动归档，点开即得冻结图 + 完整对话；F5 刷新或断线重连，进行中的编排也能无损恢复。

SAFE

安全边界

argv 注入防护、workdir 沙箱与越界拒绝、120KB 注入预算按字节截断、label 三层防伪造——子进程再多也圈在图纸内。

TEST

214 条单测

shared 87 + server 127 全绿，另有三模式 e2e（chain / PLAN / CHAT，含 ABORT 孤儿进程检查），每条手测用例都能回溯到代码位置。

结构

pnpm monorepo，三个包，一条 WebSocket。

packages/shared

类型与折叠器

图与运行的共享类型、validateGraph 校验、事件折叠器——同一套 fold 逻辑驱动实时渲染与历史重放。

apps/server :8787

编排服务端

WS 网关、AI 规划器、DAG 编排引擎、会话归档；节点是独立 spawn 的 pi 进程，与主会话互不牵连。

apps/web :5173

制图室前端

Vite + React 19 + @xyflow/react 12 + zustand，暗色可拖拽分栏；流式更新不重排布局。

快速开始

一条命令起整栈，浏览器打开 http://localhost:5173。

$ node scripts/dev.mjs          # 启动 dev 栈：server :8787 + web :5173
$ node scripts/stop.mjs          # 兜底清理残留进程

$ pnpm -r test                  # 全部单测（shared 87 + server 127）
$ node scripts/e2e-orch.mjs     # e2e：默认 chain / PLAN=1 / CHAT=1
pi-graph-ui 夜海 #0a1214 · 标绘墨 #e854d4 虚线 = 未勘测
